# Claxis Project TODO

## 1. Крейт `claxis-buffer`

* [x] `ArenaSize` лесенкой от 32КБ до 1МБ: шаг 32КБ до 128КБ, шаг 64КБ до
      512КБ, шаг 128КБ дальше. 32КБ — минимум, это 2К записей по 16 байт.
* [x] Арена состоит из блоков и **не теряет записи**: блок переполнен —
      выделяется следующий, идентификаторы стабильны.
* [x] Два стека в арене: `undo` хранит всё, `redo` — только отменённое.
* [x] `Current` — piece tree (AVL), вставка и удаление за O(log n).
* [x] Узел и сегмент по 16 байт. Источник текста выводится из записи, а не
      хранится в сегменте.
* [x] Пул узлов фиксированного размера, выделяется один раз, аллокаций в
      горячем пути нет.
* [x] Снапшот по 16K сегментов: дерево схлопывается в новый `Original`.
* [x] Тексты отменённых вставок переиспользуются: `Added` обрезается по
      хвосту, новая вставка перезаписывает это место.
* [x] Юнит-тесты на все размеры арены через `ArenaSize`.
* [x] Бенчмарки `cargo bench`, меряются вставки, а не сегменты, и видно
      сколько раз брался снапшот.
* [ ] **Выгрузка на диск при снапшоте.** Сейчас снапшот держит память в узде и
      стирает историю, но на диск ничего не пишет — при перезакрытии файла
      история теряется. Нужны формат и место хранения.
* [ ] `remaining_bytes` в буфере: сейчас есть только `remaining_records`.
