# Claxis Project TODO

## 1. Крейт `claxis-buffer`

* [x] Piece tree с балансировкой по высоте: вставка и удаление за O(log n).
* [x] Узел и сегмент по 16 байт. Источник текста выводится из записи, а не
      хранится в сегменте.
* [x] Пул узлов фиксированного размера, считается от глубины истории:
      `4 · depth + 8` узлов. Выделяется один раз, аллокаций в горячем пути нет.
* [x] Удаление вырезает сегменты физически, мёртвых сегментов не бывает.
* [x] Записи в двух стеках: `undo` хранит всё, `redo` — только отменённое.
* [x] Арена не теряет записи: блок переполнен — выделяется следующий.
* [x] Тексты отменённых вставок переиспользуются: `Added` обрезается по хвосту.
* [x] Глубина истории — единственная настройка размера, от 1 до 8192 записей.
      Ноль и превышение дают ошибку, не панику.
* [x] Снапшот по исчерпании глубины, **до** записи правки.
* [x] Ни одной паники в библиотечном коде: исчерпание пула — ошибка.
* [x] 54 теста: инварианты дерева, все срезы чтения, все позиции и диапазоны,
      границы арены, эталон на длинных случайных последовательностях.
* [x] Бенчмарки: вставка 115–150 нс независимо от размера документа, частичное
      чтение 4 КБ за 130 нс – 1.6 мкс.
* [x] Хук `SnapshotSink`: буфер отдаёт текст и ничего не знает про диск.
* [x] `set_sink` вешает приёмника на документ.
* [x] `NullSink` по умолчанию: буфер работает и без хранилища.
