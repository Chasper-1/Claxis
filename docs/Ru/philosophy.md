# Философия

Claxis — терминальный редактор для новичка. Функционал широкий, настройка простая, порог входа низкий.

## Минимализм интерфейса

Служебная информация — одна строка статус-бара. Постоянно видимых пустых командных строк и служебных панелей нет: строка ввода появляется на время работы. Место на экране принадлежит тексту.

## Два способа вызвать команду

| Механизм | Активация | Что записывает | Лейаут |
|---|---|---|---|
| Алиас | `Alt` | Символы: `dd`, `35j` | Зависит от раскладки |
| Хоткей | `Ctrl` | Физические клавиши: `vv`, `tl` | Не зависит от раскладки |

Оба работают одинаково: зажал модификатор → набрал → отпустил → выполнилось. Enter нужен только для многошаговых команд, Escape — отмена.

## Иерархические команды

Любое действие — команда вида `std::edit::move::up`. Имя намеренно многословное, чтобы по нему читался смысл. Набирать вручную не нужно: автодополнение собирает команду по уровням и подсказывает только доступные в текущем контексте.

## Контексты

Приоритет разрешения: режим → состояние → глобально. Повтор привязки в общем и узком контексте — ошибка конфига, а не перекрытие.

## Полностью переводимый интерфейс

Все строки — в TOML-файлах, ключами служат английские фразы. Имена команд `std::...` не переводятся: это часть внутренней логики. Через CLI генерируется пустой файл перевода со всеми ключами.

## Обучение, которое настраивает редактор

Встроенный курс запускается при первом старте, отключается конфигом или флагом. Уроки — не стена текста, а короткое объяснение плюс реальное действие. При изучении команды курс сразу предлагает назначить ей алиас или хоткей и записывает привязку в конфиг. К концу курса редактор персонализирован.

## Чего нет и не будет

- GUI. Ниша — терминал.
- Сплитов. Максимум — два файла одновременно.
- Эмуляции терминала. Shell-команды выполняются в каталоге проекта.
- Флага «игнорировать ошибки конфига». Ошибку исправляют, а не обходят.
