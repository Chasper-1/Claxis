## Принципы

1. Все строки интерфейса переводимы: ни одной зашитой в код строки пользовательского интерфейса.
2. Формат — TOML, по одному файлу на язык.
3. Ключи — английские фразы, они же используются в коде. В коде всегда пишется английская строка, перевод подставляется при отображении.

---

## Что не переводится

Имена команд `std::...` не переводятся: это часть внутренней логики, а не интерфейс. Переводятся только подписи, сообщения и элементы статус-бара.

---

## Подключение перевода

Активный язык задаётся ключом `language` в `config.toml`:

```toml
[General]
language = "ru"
```

Пользователь может подключить перевод любого языка, указав путь к TOML-файлу. Отсутствующие ключи откатываются к английским фразам-ключам.

---

## Шаблон перевода

CLI-команда генерирует пустой файл со всеми ключами — переводчику остаётся заполнить только значения:

```sh
claxis i18n new --lang ru
```

---

## Пример файла

```toml
# keys — английские фразы из кода, values — перевод
"Open file" = "Открыть файл"
"Save file" = "Сохранить файл"
"Unsaved changes" = "Есть несохранённые изменения"
# имена команд не переводятся и здесь не фигурируют:
# std::file::open остаётся std::file::open
```

Подписи режимов в статус-баре вынесены в конфиг, а не в файл перевода, — см. [config.md](config.md).
