# Локализация

## Принципы

Все надписи интерфейса переводимы, ничего не зашивается в код пользовательского интерфейса. Формат — TOML, по одному файлу на язык. Ключи — английские фразы, они же используются в коде: в коде всегда пишется английская строка, перевод подставляется при отображении.

## Что не переводится

Имена команд `std::...` не переводятся: это часть внутренней логики, а не интерфейс. Переводятся подписи, сообщения и элементы статус-бара. Подписи режимов вынесены в конфиг, а не в файл перевода.

## Подключение перевода

Активный язык задаётся ключом `language` в конфиге.

```toml
[General]
language = "ru"
```

Пользователь может подключить перевод любого языка, написав по пути `~/.config/claxis/lang/` TOML файл с переводом. Название должно быть в формате `ru.toml`, где `ru` — код языка. Отсутствующие ключи являются ошибкой при переводе и необходимо заполнить все ключи, чтобы перевод считался валидным.

## Шаблон перевода

CLI-команда генерирует пустой файл со всеми ключами — переводчику остаётся заполнить только значения.

```sh
claxis i18n new --lang ru
```

`В планах добавить режим для проверки переводов. Подробности позже.`

## Пример файла

```toml
"Open file" = "Открыть файл"
"Save file" = "Сохранить файл"
"Unsaved changes" = "Есть несохранённые изменения"
```

Имена команд не переводятся и в файле перевода не фигурируют: `std::file::open` остаётся `std::file::open`.
