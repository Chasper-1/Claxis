# Модель ввода

## Состояния

Состояние — глобальный контекст, домен команд. Активно ровно одно состояние.

| Состояние | Назначение |
|---|---|
| `edit` | Правка текста |
| `command` | Ввод команд под модификатором (по умолчанию) |
| `files` | Работа с файлами и Git |
`Состояние по умолчанию можно изменить в конфиге.`

## Модификаторы

Оба переназначаются в конфиге.

| | Модификатор символов | Модификатор позиций |
|---|---|---|
| По умолчанию | `Alt` | `Ctrl` |
| Что записывает | символ как есть | абсолютный символ |
| Раскладка | важна | не важна |
| Пример | `dd` в qwerty, `вв` в русской | `d` и `в` — одно и то же |

Различие только в том, как читается нажатие. Всё остальное — выполнение при отпускании, отмена, повторы, подсказки — одинаково.

## Режимы

Режим — узкое разделение внутри состояния. Активно ровно один режим внутри состояния.

### Режимы Edit

| Режим | Назначение |
|---|---|
| `type` | Стандартный ввод с курсором |
| `view` | Только навигация, буфер не меняется |
| `replace` | Ввод заменяет символы по ходу набора |
| `selection` | Выделение |
| `search` | Поиск и замена |

### Режимы Files

| Режим | Назначение |
|---|---|
| `browse` | Навигация по файловой системе |
| `git` | Операции Git: коммит, дифф, ветки |
| `search` | Поиск и замена |
| `selection` | Выделение |

### Состояние Command

Внутренних режимов не имеет: ввод команды → отпускание модификатора → выполнение. Это линейная последовательность, а не набор подконтекстов.

Имена режимов задаются в конфиге, по ним же подбираются цвета темы. Минимум две буквы для режимов, однобуквенные оставлены под короткие алиасы.

## Лидер

Пробел — лидер-клавиша, удваивает доступное число комбинаций. Работает как префикс командного ввода, отдельным режимом не является.

Лидер клавиша используется везде одинаково: В хоткеях это просто клавиша, в алиасах это символ. В обоих случаях, может использоваться в командном режиме как первая клавиша в комбинации.

## Переключение состояний

Между состояниями переключаются только командами. Отдельных клавиш для переключения нет по умолчанию.

## Индикация

Активный режим показывается в статус-баре: подпись из конфига и цвета из темы. Отдельных панелей и всплывающих плашек нет. При `color_modes = true` режим выделяется цветным фоном.

Название состояния и режима видно всегда, строка ввода и подсказки — пока идёт работа с командной строкой.
