## Два уровня управления

| Уровень | Что это | Пример |
|---|---|---|
| **Состояние** | Глобальный контекст: что делают клавиши | Edit, File, Search, Command |
| **Режим** | Узкое разделение внутри состояния | insert, select, view, replace |

Активно ровно одно состояние и один режим внутри него. Состояние задаёт домен команд, режим — конкретный контекст внутри домена.

---

## Режимы

Имена состояний и режимов зафиксированы в конфиге — по ним же подбираются цвета темы:

| Ключ | Подпись | Что это |
|---|---|---|
| `edit` | Edit | Правка текста (состояние по умолчанию) |
| `command` | Command | Ввод алиасов под Alt |
| `search` | Search | Поиск и замена |
| `files` | Files | Работа с файлами и Git |
| `selection` | Selection | Выделение |
| `hotkeys` | Hot-keys | Ввод физических клавиш под Ctrl |

Ключи `edit`, `command`, `search`, `files`, `selection`, `hotkeys` обязательны в двух местах: `name_modes` в статус-баре и `modes` в теме.

## Состояния и режимы внутри

### Edit — состояние правки

| Режим | Назначение |
|---|---|
| `insert` | Стандартный ввод с курсором (по умолчанию) |
| `view` | Только навигация, ввод не меняет буфер |
| `selection` | Расширение выделения движениями курсора |
| `replace_char` | Ввод сразу заменяет символ под курсором, курсор идёт вперёд |

Правило именования режимов: **минимум 2 буквы**. Однобуквенные имена оставлены под быстрые алиасы.

### File — состояние файлов

| Режим | Назначение |
|---|---|
| `browse` | Навигация по файловой системе |
| `git` | Операции Git: коммит, дифф, ветки |

### Search — состояние поиска

| Режим | Назначение |
|---|---|
| `text` | Поиск по тексту |
| `regex` | Поиск по регулярному выражению |
| `filter` | Фильтрация по критериям |

Точечная и глобальная замена выполняются в одном интерфейсе этого состояния.

### Command — командный режим

Внутренних режимов не имеет: ввод алиаса → отпускание Alt → выполнение. Это линейная последовательность, а не набор подконтекстов.

---

## Командный режим

| Параметр | Поведение |
|---|---|
| Активация | Зажатие `Alt`; сам Alt команд не выполняет |
| Ввод | Алиасы: `dd`, `35j`, `yy` |
| Выполнение | При отпускании `Alt`, Enter не нужен |
| Enter | Только для многошаговых команд |
| Escape | Отмена, если уже что-то написано |
| Пустой ввод | Ничего не происходит |
| Невалидный ввод | Ничего не происходит |
| Лейаут | **Зависит**: `d` и `в` — разные символы |
| Отображение | По центру экрана, если `center_mode = true` |

Правила алиасов:

| Правило | Смысл |
|---|---|
| Числовой префикс | Повторение: `3dd` — три строки, `10j` — на десять строк вниз |
| Выполнение при отпускании | Ввод копится и выполняется целиком |
| Многошаговые алиасы | Требуют подтверждения Enter |

Примеры: `dd` — удалить строку, `3dd` — три строки, `yy` — скопировать, `35j` — вниз на 35 строк, `p` — вставить.

## Режим хоткеев

| Параметр | Поведение |
|---|---|
| Активация | Зажатие `Ctrl` |
| Ввод | Последовательности физических клавиш: `vv`, `tl` |
| Выполнение | При отпускании `Ctrl`, Enter не нужен |
| Лейаут | **Не зависит**: `d` и `в` — одно физическое нажатие |
| Перекрытие | Перекрывает ввод текста: `Ctrl+s` сохраняет, а не печатает `s` |

### Отличие от алиасов

| | Хоткеи (Ctrl) | Алиасы (Alt) |
|---|---|---|
| Что записывает | Физическую клавишу | Символ |
| Лейаут | Не зависит | Зависит |
| Пример | `d` и `в` — одно и то же | `d` и `в` — разное |
| Сценарий | Работает у себя в любой раскладке | Сокращения на своём языке |

## Лидер

Пробел — **лидер-кавиша**: удваивает доступное число комбинаций.

| Параметр | Поведение |
|---|---|
| Клавиша | Пробел |
| Механика | Лидер + комбинация = альтернативная команда |
| Конфликт с вводом | Нет: в режиме ввода пробел вставляет пробел |

Лидер работает как префикс хоткея, а не как отдельный режим.

---

## Переключение

Между состояниями переключаются **только через командный режим** — алиасами под Alt. Отдельных хоткеев и F-клавиш для переключения нет. При старте активно состояние Edit.

| Свойство | Правило |
|---|---|
| Один активный контекст | Трансляцию нажатий выполняет ровно один контекст |
| Явные переходы | Смена состояния только по команде или привязке |
| Возврат | Из командного режима и хоткеев — по завершении ввода |

## Логика курсора

Логика перемещения единая для всех состояний:

| Движение | Единицы |
|---|---|
| По символам | влево / вправо |
| По словам | к началу / к концу слова |
| По строкам | вверх / вниз |
| По строке | к началу / к концу строки |

Поддерживается количество повторений — тем же механизмом, что и числовой префикс алиаса. Модель курсора — в [buffer-and-cursors.md](buffer-and-cursors.md).

---

## Индикация

Активный режим показывается в статус-баре: подпись из `name_modes` и цвета из темы. Отдельных панелей и всплывающих плашек нет. При `color_modes = true` режим выделяется цветным фоном.
