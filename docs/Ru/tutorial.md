## Запуск и отключение

Курс запускается автоматически при первом старте редактора. Способы его не увидеть:

| Способ | Механизм |
|---|---|
| Отключить заранее | Параметр в конфиге |
| Пропустить разово | Флаг запуска из командной строки |
| Прервать по ходу | Досрочное завершение в любой момент |

## Формат курса

Курс — практический мини-курс, а не стена текста:

- короткие объяснения плюс практические задания;
- задание — реальное действие: переместить курсор, создать алиас;
- проверка нестрогая: достаточно выполнить действие;
- никаких проверок «на идиота» — курс доверяет пользователю.

---

## Настройка через обучение

Обучение одновременно персонализирует редактор:

1. При изучении команды курс предлагает **сразу назначить ей алиас или хоткей**.
2. Назначение записывается прямо в конфиг.
3. К концу курса редактор персонализирован: пользователь уходит с рабочим конфигом под свои привычки.

## Хранение уроков

| Вариант | Особенность |
|---|---|
| Встроены в бинарник | Работают всегда, без файлов |
| Внешние файлы (TOML) | Загружаются как данные, формат тот же, что у конфигов |

Пользовательские уроки возможны: сообщество может писать свои обучающие материалы в том же формате.

---

## Связь с макросами

Урок может предложить **записать последовательность действий как макрос и повесить на него алиас**. Так пользователь сразу осваивает автоматизацию рутины, а не только навигацию. Формат макроса — в [plugins.md](plugins.md).

---

## Схема урока

Черновик схемы урока в TOML:

```toml
[[lesson]]
id = "edit-move-cursor"                      # уникальный идентификатор
text = "Наберите алиас std::edit::move::down под Alt"
task = "Переместите курсор вниз командой"     # задание
done_when = { command = "std::edit::move::down" } # критерий выполнения
next = "edit-delete-line"                     # следующий урок
```

| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор урока |
| `text` | Короткое объяснение |
| `task` | Практическое задание |
| `done_when` | Критерий выполнения |
| `next` | Идентификатор следующего урока |

Схема — черновик: поля могут уточняться при реализации движка, но состав зафиксирован именно такой.
