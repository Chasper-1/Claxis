## Запуск и отключение

Интерактивный курс запускается **автоматически при первом старте** редактора. Способы его не увидеть:

| Способ | Механизм |
|---|---|
| Отключить заранее | Параметр в конфиге ([`config.md`](config.md)) |
| Пропустить разово | Флаг запуска из командной строки |
| Прервать по ходу | Досрочное завершение в любой момент |

## Формат курса

Курс — не стена текста, а практический мини-курс:

- **короткие объяснения** + **практические задания**;
- задания — реальные действия: переместить курсор, создать алиас;
- **проверка нестрогая** — достаточно выполнить действие;
- никаких тестов «на идиота» — курс доверяет пользователю.

## Настройка через обучение

Обучение — это одновременно персонализация редактора:

1. При изучении команды курс предлагает **сразу назначить ей алиас или хоткей**.
2. Назначения записываются **прямо в конфиг**.
3. К концу курса редактор полностью персонализирован: пользователь уходит с рабочим конфигом под свои привычки.

## Хранение уроков

Уроки могут храниться двумя способами:

| Вариант | Особенность |
|---|---|
| **Встроены в бинарник** | Работают всегда, без файлов |
| **Внешние файлы (TOML)** | Загружаются как данные; формат тот же, что у конфигов |

**Пользовательские уроки возможны**: сообщество может создавать собственные обучающие материалы в том же формате.

## Связь с макросами

Курс связан с системой плагинов ([`plugins.md`](plugins.md)): урок может предложить **записать последовательность действий как макрос и повесить на него алиас**. Так пользователь сразу осваивает автоматизацию рутины.

## Схема урока

Черновик схемы урока (TOML):

```toml
# Урок edit-move-cursor
[[lesson]]
id = "edit-move-cursor"                # уникальный идентификатор урока
text = "Нажмите Alt+`, наберите std::edit::move::down и Enter"
task = "Переместите курсор вниз командой"  # задание
done_when = { command = "std::edit::move::down" } # критерий выполнения
next = "edit-select-line"              # следующая команда (id следующего урока)
```

| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор урока |
| `text` | Короткое объяснение |
| `task` | Практическое задание для пользователя |
| `done_when` | Критерий выполнения (выполнено указанное действие) |
| `next` | Идентификатор следующего урока |

Схема — черновик; поля могут уточняться при реализации движка обучения, но состав зафиксирован именно такой.
