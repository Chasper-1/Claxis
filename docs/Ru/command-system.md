# Система команд

## Клавиша и раскладка

Клавиша — это позиция на клавиатуре, а не символ. Одна и та же позиция в разных раскладках даёт разные символы: `d` в qwerty, `в` в русской. Что на этой позиции стоит в текущей раскладке, то и печатается.

Редактор получает от терминала символ, а не позицию, поэтому путь до клавиши восстанавливается через раскладку: символ → позиция этого символа в активной раскладке → символ эталонной раскладки на той же позиции.

Эталонная раскладка — точка отсчёта, по умолчанию qwerty, меняется конфигом. Раскладки, совпадающие с эталоном, перечислять не нужно. Терминал сообщений о смене раскладки не присылает, поэтому активная раскладка либо определяется по вводу, либо задаётся пользователем явно.

## Алиасы

Короткое сокращение, разворачивается в команду. Вводится под модификатором символов.

Сравнивается напрямую: что напечатали, то и ищем, поэтому от раскладки зависит. В qwerty срабатывает `dd`, в русской нужно `вв`.

```toml
[Aliases.global]
dd = "std::edit::delete::line"
yy = "std::edit::copy::line"
j  = "std::edit::move::down"
p  = "std::clipboard::paste"
```

## Хоткеи

Последовательность клавиш под модификатором позиций. Записывается позиция, а не символ, поэтому от раскладки не зависит: `Ctrl`+`d` и `Ctrl`+`в` — одна и та же привязка.

```toml
[Hotkeys.global]
"Ctrl+s" = "std::file::save"
"Ctrl+i" = "std::mode::edit"
" space s" = "std::file::save"
```

Все сочетания пишутся в эталонной раскладке. Клавиши, не дающие символа — стрелки, `F1`–`F12`, `Home`, `End`, `PageUp`, `PageDown`, `Tab`, `Enter`, `Backspace`, `Delete` — привязываются напрямую.

Лидер принадлежит только хоткеям: пробел — позиция клавиши, а у алиасов значением является символ, и там пробел бессмыслен, потому что в русской раскладке на этой позиции `ж`.

## Уровни

Каждый механизм настраивается на трёх уровнях: `global` → `state` → `regime`.

Глобальный уровень — база, он блокирует остальные, потому что действует везде. Поиск идёт сверху вниз, первое найденное назначение выигрывает.

```toml
[Aliases.global]
dd = "std::edit::delete::line"

[Aliases.edit]
h = "std::edit::move::left"

[Aliases.edit.command]
v = "std::edit::select::start"
```

Алиасы и хоткеи на одном уровне независимы: настраиваются раздельно, в разных секциях, изменение одного не влияет на другой.

## Конфликты

Одна и та же клавиша на разных уровнях — ошибка конфигурации. Наложить локальную привязку поверх глобальной нельзя.

Сообщение называет клавишу и уровни, где она стоит, плюс строку файла. Запуск со сломанным конфигом не продолжается, флага «игнорировать ошибки» нет намеренно.

Тень привязки означала бы, что поведение клавиши зависит от того, где находится пользователь, и от того, помнит ли он про исключение. Дубликат ловится при загрузке, а не при работе.

## Команды

Команда — иерархическая строка с разделителем `::`.

```
std::edit::move::up
std::edit::delete::line
std::file::save
std::mode::command
```

| Уровень | Что содержит |
|---|---|
| Пространство | `std` — встроенные, `plugin-id` — из плагинов |
| Домен | `edit`, `file`, `mode`, `search`, `macro` |
| Действие | `move`, `delete`, `select`, `open`, `save` |
| Уточнение | `up`, `line`, `word_start` |

Имя намеренно многословное, чтобы по нему читался смысл. Имена команд не переводятся: это внутренняя логика, а не интерфейс.

## Командная строка

Строка собирается из числа повторов, имени и аргументов, в любом порядке. Разделитель один — пробел.

Выполняется при отпускании модификатора, `Enter` нужен для многошаговых команд, `Escape` отменяет. Пустой и невалидный ввод ничего не делают. История листается `↑` и `↓`, подсветка показывает структуру строки.

По центру экрана при `center_mode = true`, иначе в строке ввода. Строка скрыта, пока не используется, при `hide = true`.

## Автодополнение

Набор по уровням, с учётом активного состояния и режима.

```text
std::              ← edit / file / mode / search / macro
std::edit::        ← move / delete / select
std::edit::move::  ← up / down / word / start
std::edit::move::up⏎
```

После `::` предлагаются только продолжения текущего уровня, недоступные в текущем контексте команды не показываются. При единственном совпадении дописывается сразу, при нескольких показывается весь список.

## Повторения

Числовой префикс — количество повторений. `5dd` удаляет пять строк, `10j` идёт вниз на десять строк, `3 std::edit::move::word::right` смещается на три слова вправо.

Механизм один для алиасов и полных имён, работает там, где повтор уместен по смыслу команды.

## Shell-команды

Выполнение shell-команды — отдельный механизм, не смешивается с внутренними командами и алиасами.

Рабочий каталог — директория открытого файла или проекта. Оболочка `sh -c` на unix, `cmd /C` на windows. Эмуляция терминала не делается, вывод показывается в отдельном окне.
