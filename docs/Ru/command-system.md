## Обзор

Любое действие сводится к команде. Два способа её вызвать:

| Способ | Активация | Что записывает | Лейаут |
|---|---|---|---|
| **Алиас** | `Alt` | Символы: `dd`, `35j`, `yy` | Зависит |
| **Хоткей** | `Ctrl` | Физические клавиши: `vv`, `tl` | Не зависит |

Оба работают одинаково: зажал модификатор → набрал → отпустил → выполнилось. `Enter` нужен только для многошаговых команд, `Escape` — отмена. Без модификатора нажатие — обычный ввод текста.

## Команды

Команда — иерархическая строка с разделителем `::`:

```
std::edit::move::up
std::edit::delete::line
std::file::save
```

| Свойство | Смысл |
|---|---|
| Многословность | По имени понятно, что делает команда |
| Иерархия | Пространство `std`, домен `edit`/`file`, действие `move`/`delete`, уточнение `up`/`line` |
| Автодополнение | Собирается по уровням, учитывает текущий контекст |

```text
> std::              ← edit / file / search
> std::edit::        ← move / delete / select
> std::edit::move::  ← up / down / word_start
> std::edit::move::up⏎
```

Ручной набор не требуется.

## Алиасы

Короткое текстовое сокращение, вводится под `Alt`:

| Алиас | Разворачивается в |
|---|---|
| `dd` | `std::edit::delete::line` |
| `yy` | `std::edit::copy::line` |
| `35j` | `std::edit::move::down` с повтором 35 |

Правила:

- `Alt` — переключатель режима, сам по себе команду не выполняет;
- выполнение при отпускании `Alt`, `Enter` не нужен;
- `Enter` — только для многошаговых команд;
- `Escape` — отмена, если уже что-то написано;
- пустой ввод — ничего не происходит;
- неизвестный алиас — ничего не происходит;
- числовой префикс — количество повторений: `3dd` удаляет три строки.

## Хоткеи

Последовательность физических клавиш под `Ctrl`:

| Параметр | Поведение |
|---|---|
| Активация | Зажатие `Ctrl` |
| Ввод | `vv`, `tl`, `Ctrl+s` |
| Выполнение | При отпускании `Ctrl` |
| Физические клавиши | Записывается нажатие, а не символ |
| Лейаут | Независим: `d` и `в` — одно и то же |
| Перекрытие | Перекрывает ввод: `Ctrl+s` сохраняет, а не печатает `s` |

| | Хоткеи (Ctrl) | Алиасы (Alt) |
|---|---|---|
| Что записывает | Физическую клавишу | Символ |
| Лейаут | Независим | Зависит |
| Сценарий | Работает в любой раскладке | Сокращения на своём языке |

## Контексты и приоритеты

Алиасы и хоткеи — независимые механизмы: настраиваются раздельно, в разных секциях конфига, изменение одного не влияет на другой.

Привязка живёт на одном из трёх уровней:

| Уровень | Действует |
|---|---|
| `regime` | Внутри одного режима состояния |
| `state` | Во всех режимах состояния |
| `global` | Всегда |

Разрешение идёт от узкого к общему: сначала режим, затем состояние, затем глобальные определения. Если привязка не найдена ни на одном уровне, нажатие не обрабатывается.

## Повторения

Команда принимает количество повторений:

| Ввод | Действие |
|---|---|
| `5dd` | Удалить 5 строк |
| `3std::edit::move::word_right` | Сместиться на 3 слова вправо |
| `10j` | Вниз на 10 строк |

Механизм один и тот же для командной строки и для алиасов: повторение работает там, где оно уместно по смыслу команды.

## Конфликты

**Привязка, продублированная в общем и узком контексте, — ошибка конфигурации.**

| Правило | Пояснение |
|---|---|
| Запуск со сломанным конфигом | Не продолжается |
| Восстановление | Средствами редактора: точное сообщение об ошибке либо автозапуск на последней рабочей версии с открытым сломанным файлом |
| Флаг «игнорировать ошибки» | Отсутствует намеренно |

Обходной путь маскирует проблему и даёт невоспроизводимое поведение — ошибку исправляют, а не обходят.

## Командная строка

| Функция | Поведение |
|---|---|
| Активация | Зажатие `Alt` |
| Ввод | Алиасы |
| Выполнение | При отпускании `Alt` |
| Длительность | Сколько угодно, пока `Alt` зажата |
| Автодополнение | По иерархии команд, с учётом контекста |
| История | Навигация `↑` / `↓` |
| Подсветка | Структура команды, алиаса и числа повторений |
| Подсказки | Список вариантов под строкой ввода |
| Отображение | По центру экрана при `center_mode = true`, иначе в строке ввода |
| Скрытие | Строка скрыта, пока не используется, при `hide = true` |
