# Система команд

## Клавиша и раскладка

Клавиша — это позиция на клавиатуре, а не символ. Одна и та же позиция в разных раскладках даёт разные символы: `d` в qwerty, `в` в русской. Что на этой позиции стоит в текущей раскладке, то и печатается.

Редактор получает от терминала символ, а не позицию, поэтому путь до клавиши восстанавливается через раскладку: символ → позиция этого символа в активной раскладке → символ эталонной раскладки на той же позиции.

Эталонная раскладка — точка отсчёта. Можно изменить раскладку относительно qwerty на любую другую эталонную. Раскладки, совпадающие с эталоном, перечислять не нужно. Терминал не сообщает о смене раскладки, поэтому активная раскладка либо определяется по вводу, либо задаётся пользователем явно.

## Алиасы

Короткое сокращение, разворачивается в команду. Вводится под модификатором символов.

Сравнивается напрямую: что напечатали, то и ищем, поэтому от раскладки зависит. В qwerty срабатывает `dd`, в русской печается вв, вместо dd, работать алиас не будет.

`Регистр символа так же имеет значения!`

```toml
[Aliases.global]
dd = ":std::edit::delete::line"
yy = ":std::edit::copy::line"
j  = ":std::edit::move::down"
p  = ":std::clipboard::paste"
```

## Хоткеи

Последовательность клавиш под модификатором позиций. Записывается позиция, а не символ, поэтому от раскладки не зависит: `Ctrl`+`d` и `Ctrl`+`в` = `Ctrl`+`d` — одна и та же привязка.

```toml
[Hotkeys.global]
"Ctrl+s" = ":std::file::save"
"Ctrl+i" = ":std::mode::edit"
"space s" = ":std::file::save"
```

Хоткеи пишутся в специальном режиме, который активируется нажатием `Ctrl` по умолчанию.

Все сочетания пишутся в эталонной раскладке. Клавиши, не дающие символа — стрелки, `F1`–`F12`, `Home`, `End`, `PageUp`, `PageDown`, `Tab`, `Enter`, `Backspace`, `Delete` — привязываются напрямую.

Лидер клавиша используется везде одинаково: В хоткеях это просто клавиша, в алиасах это символ. В обоих случаях, может использоваться в командном режиме как первая клавиша в комбинации.


## Уровни

Каждая комбинация настраивается на трёх уровнях: `global` → `state` → `regime`.

Глобальный уровень — база, он блокирует остальные, потому что действует везде. Так работает с каждым нижним уровнем при назначении такой же комбинации назначеной на верхнем уровне.

```toml
[Aliases.global]
dd = ":std::edit::delete::line"

[Aliases.edit]
h = ":std::edit::move::left"

[Aliases.edit.search]
s = ":std::edit::search"
```

Алиасы и хоткеи на одном уровне независимы: настраиваются раздельно, в разных секциях, изменение одного не влияет на другой.

## Конфликты

Одна и та же клавиша в глобальном и локальном уровнях — ошибка.

Подсказка называет символ и уровень, где она стоит, плюс строку файла. Запуск со сломанным конфигом не продолжается, флага «игнорировать ошибки» нет намеренно.

Проверка работает следующим образом: при нажатии клавиши, сначала проверяется глобальный уровень, затем локальный, и только потом выполняется команда.

## Команды

Команда — иерархическая строка имеет начало после `:` и разделителем `::`.

```
:std::edit::move::up
:std::edit::delete::line
:std::file::save
:std::mode::command
```

| Уровень | Что содержит |
|---|---|
| Пространство | `:std` — встроенные, `plugin-id` — из плагинов |
| Домен | `edit`, `file`, `mode`, `search`, `macro` |
| Действие | `move`, `delete`, `select`, `open`, `save` |
| Уточнение | `up`, `line`, `word_start` |
`На данный момент таблица ничего не значит в реальности.`

Имя намеренно многословное, чтобы по нему читался смысл. Имена команд не переводятся: это внутренняя логика, а не интерфейс.

## Командная строка

Строка собирается из имени, числа повторов и аргументов, в указаном порядке. Разделитель — пробел.
Те же команды доступны из shell, что позволяет скриптом настроить редактор не заходя в него.

Выполняется при отпускании модификаторов `Ctrl` и `Alt`. `Enter` нужен для многошаговых команд, `Escape` отменяет. Пустой и невалидный ввод ничего не делают. История листается `↑` и `↓`, подсветка показывает структуру строки.

По центру экрана при `center_mode = true`, иначе в строке ввода. Строка скрыта, пока не используется, при `hide = true`.

## Автодополнение

Набор по уровням, с учётом активного состояния и режима.

```text
:std::              ← edit / file / mode / search / macro
:std::edit::        ← move / delete / select
:std::edit::move::  ← up / down / word / start
:std::edit::move::up⏎
```
Автодополнение начинает работать после `:`, предлагая выбор между std командами и от плагинов, с их кастомными именами.

После `std::` предлагаются только продолжения текущего уровня, недоступные в текущем контексте команды не показываются. При единственном совпадении дописывается сразу, при нескольких показывается весь список.

## Повторения

Числовой префикс — количество повторений. `5dd` удаляет пять строк, `10j` идёт вниз на десять строк, `3:std::edit::move::word::right` смещается на три слова вправо.

Использовать повтор можно будет в указаных для этого командах из документации, обучения или в подсказках при написании команд.

## Shell-команды

Выполнение shell-команды — отдельный механизм, не смешивается с внутренними командами и алиасами.

Рабочий каталог — директория открытого файла или проекта. Оболочка `sh -c` на unix, `cmd /C` на windows. Эмуляция терминала не делается. Об выполненой команде приходит уведомление.
