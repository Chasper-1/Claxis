# Модель ввода

## Состояния

Состояние — глобальный контекст, домен команд. Активно ровно одно состояние.

| Состояние | Назначение |
|---|---|
| `edit` | Правка текста (по умолчанию) |
| `command` | Ввод команд под модификатором |
| `search` | Поиск и замена |
| `files` | Работа с файлами и Git |
| `selection` | Выделение |

## Модификаторы

Оба переназначаются в конфиге.

| | Модификатор символов | Модификатор позиций |
|---|---|---|
| По умолчанию | `Alt` | `Ctrl` |
| Что записывает | символ как есть | позицию клавиши |
| Раскладка | важна | не важна |
| Пример | `dd` в qwerty, `вв` в русской | `Ctrl`+`d` и `Ctrl`+`в` — одно и то же |

Различие только в том, как читается нажатие. Всё остальное — выполнение при отпускании, отмена, повторы, подсказки — одинаково.

## Режимы

Режим — узкое разделение внутри состояния. Активно ровно один режим внутри состояния.

### Режимы Edit

| Режим | Назначение |
|---|---|
| `insert` | Стандартный ввод с курсором (по умолчанию) |
| `view` | Только навигация, буфер не меняется |
| `replace_char` | Ввод заменяет символ под курсором |

### Режимы Files

| Режим | Назначение |
|---|---|
| `browse` | Навигация по файловой системе |
| `git` | Операции Git: коммит, дифф, ветки |

### Режимы Search

| Режим | Назначение |
|---|---|
| `text` | Поиск по тексту |
| `regex` | Поиск по регулярному выражению |
| `filter` | Фильтрация по критериям |

### Состояние Command

Внутренних режимов не имеет: ввод команды → отпускание модификатора → выполнение. Это линейная последовательность, а не набор подконтекстов.

### Состояние Selection

Выделение текста. Внутренних режимов не имеет.

Имена режимов задаются в конфиге, по ним же подбираются цвета темы. Минимум две буквы, однобуквенные оставлены под короткие алиасы.

## Командный ввод

Слой чтения нажатий, а не отдельное состояние. Активен, когда эффективный режим командный: в базовом режиме `command` или под модификатором в режиме `edit`.

Выполняется при отпускании модификатора. Строка ввода появляется на время работы и не висит на экране. `Enter` нужен только для многошаговых команд, `Escape` отменяет набранное. Пустой и невалидный ввод ничего не делают.

Строка собирается из числа повторов, имени и аргументов, в любом порядке. Разделитель один — пробел.

`dd` удаляет строку. `35j` идёт вниз на 35 строк. `3dd` удаляет три строки. `std::edit::move::down` — полное имя команды. `std::file::open path.txt` — имя и аргумент.

## Лидер

Пробел — лидер-кавиша, удваивает доступное число комбинаций. Работает как префикс командного ввода, отдельным режимом не является. В режиме ввода пробел вставляет пробел.

Лидер принадлежит только модификатору позиций: пробел — позиция клавиши, а у символов значением является символ, и там это не имеет смысла, потому что в русской раскладке на этой позиции `ж`.

## Переключение состояний

Между состояниями переключаются только командами — алиасами или хоткеями. Отдельных клавиш для переключения нет.

При старте активно состояние `edit`.

## Упрощённая поддержка Alt

Для терминалов без kitty keyboard protocol — упрощённая поддержка модификатора символов:

- Нажатие модификатора переводит в командное состояние.
- Повторное нажатие возвращает в предыдущее состояние.

С протоколом — двойное нажатие в течение небольшого времени переходит в командное состояние, ещё раз — обратно.

## Логика курсора

Единая для всех состояний и режимов: по символам влево и вправо, по словам к началу и к концу слова, по строкам вверх и вниз, по строке к началу и к концу строки.

Поддерживается количество повторений, тем же механизмом, что и числовой префикс.

## Индикация

Активный режим показывается в статус-баре: подпись из конфига и цвета из темы. Отдельных панелей и всплывающих плашек нет. При `color_modes = true` режим выделяется цветным фоном.

Название состояния и режима видно всегда, строка ввода и подсказки — пока идёт работа с командной строкой.
