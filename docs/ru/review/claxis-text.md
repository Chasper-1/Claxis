# Ревью: `claxis-text`

Дата ревью: 2026-11-12 (вторая версия, пересмотрено по критерию «только свои
правила и согласованность кода с самим собой»).
Состояние крейта: 507 строк, 23 теста, все проходят.

## 1. Назначение и границы

Крейт — нижний слой: общие примитивы для текста, которые нужны всем сразу.

| Что есть | Что не входит в крейт |
| --- | --- |
| `substitute` — подстановка значений в шаблон сообщения | Каталог переводов и его разбор — `claxis-i18n` |
| `group_digits` — разбивка числа на разряды | Решение, где показывать число, — вызывающий |
| `grapheme::next` / `grapheme::prev` — границы графем в байтах | Раскладки, ширина, нормализация |

Зависимость одна: `unicode-segmentation`. Крейт ничего не знает про диск,
конфиг и терминал — границы соблюдены.

Прямая зависимость остальных крейтов на `claxis-text` правилу «крейты
напрямую» не противоречит: `text` — лист, у него нет соседей, о которых
можно знать.

## 4. Что сделано хорошо

- **Границы графем считаются локально.** `next`/`prev` не обходят весь текст:
  время шага зависит от длины графемы, а не от длины строки.
- **Эталон полного обхода в тестах.** `full_next`/`full_prev` — простой,
  медленный, заведомо правильный способ. Тест `local_walk_matches_a_full_scan`
  сверяет быстрый путь с эталоном на наборе строк, включая длинные цепочки
  комбинирующих знаков, ZWJ-эмодзи и пары региональных индикаторов.
- **Битый UTF-8 не останавливает курсор.** `a\xFFb` пройден целиком в обе
  стороны; при невалидных байтах функция ведёт себя как «один байт — одна
  графема».
- **`\r\n` — одна графема.** Проверено отдельно, обход назад тоже.
- **Тесты проверяют смысл, а не только результат.** `grouping_never_loses_digits`
  проверяет по кругу, что разбивка не теряет цифры.
- **Разделитель разрядов выбран и записан в коде** вместе с причиной.

## 5. Находки

| # | Серьёзность | Где | Что не так |
| --- | --- | --- | --- |
| 1 | важно | `src/lib.rs:15` | `substitute` подставляет значения по порядку, и значение, вставленное раньше, может быть изменено более поздней заменой. Комментарий в тесте `a_value_containing_another_name_does_not_expand_further` и само имя теста утверждают обратное: «значение не должно запускать новую подстановку внутри себя» — а проверка требует `"2 2"`, то есть подстановка внутри значения происходит |
| 2 | мелочь | `src/lib.rs:15` | `substitute` делает по одному проходу `replace` на каждое значение: столько же проходов по строке и столько же аллокаций |

### К находке 1 подробнее

```rust
substitute("{a} {b}", &[("a", "{b}".to_string()), ("b", "2".to_string())])
```

Первый проход даёт `"{b} {b}"`, второй — `"2 2"`. Значение, попавшее в текст,
обрабатывается дальше как шаблон.

Чем это опасно по правилам проекта: правило «Неизвестное из конфига, базы,
блоба — ошибка. Не ноль, не дефолт» относится к данным, а здесь значение,
пришедшее из данных, может быть подменено текстом шаблона. Имя файла или путь
с `{...}` совпадёт с ключом каталога — и текст сообщения молча станет другим.

Что предлагается: подстановка одним проходом по шаблону — идти слева направо,
на `{имя}` подставлять значение целиком, содержимое вставленного значения не
просматривать. Поведение станет «значение вставляется как есть», а тест сможет
честно называться `a_value_containing_another_name_is_inserted_as_is`.

## 7. Тесты

23 теста, все проходят.

| Что покрыто | Чего не хватает |
| --- | --- |
| ASCII, комбинирующие знаки, ZWJ-эмодзи, флаги, Hangul, `CRLF` | — |
| Битый UTF-8 в обе стороны | Сравнение с эталоном на строках с битыми байтами в середине многобайтного символа |
| Границы локального окна: `\r\n`, позиция внутри символа | Поведение `prev` на куске, вырезанном из середины строки, — не закреплено |
| Согласие быстрого пути с полным обходом | Проверки, что `next`/`prev` не выходят за пределы куска при `at` за границей, — только на ASCII |
| `substitute`: неизвестные имена, повтор имени, пустое значение, ничего не подставлять | Случай, когда значение содержит имя из каталога, — проверяется, но с ожиданием, противоречащим комментарию (находка 1) |
| `group_digits`: границы по тройкам, короткие числа, цифры не теряются | — |

Тесты крейта сильные. При исправлении `substitute` ожидание в тесте надо
переписать, а не просто поправить.
