# Ревью крейтов

Поразборное ревью кода по крейтам: один крейт за заход, один файл на крейт.
Файлы описывают, что сделано хорошо, что сломано и что предлагается делать.
Правки в коде по итогам ревью — отдельными заходами.

## Чем это ревью меряет

Только своим, а не чужим:

1. **Правила проекта из `AGENTS.md`.** Нарушение правила — находка.
2. **Согласованность кода с самим собой.** Код против его же документации,
   комментариев, тестов и соседнего кода. Расхождение — находка.
3. **Потеря данных, паника, неправдивое сообщение.** Ошибка доходит до
   пользователя текстом, молчать можно только с комментарием, почему и кто
   узнает.

Чего здесь нет и не будет:

- оценок по внешним стандартам и сторонним инструментам (формат файла, который
  читает только сам редактор, — это его формат, и он рабочий);
- вкусовых замечаний («лучше бы так», «я бы назвал иначе»);
- предположений о том, как проект должен выглядеть в будущем: это решает
  владелец, а не ревью.

Формат файлов, состав и разделы — как в первом заходе. Находки пересмотрены:
часть прежних снята (см. «Что снято и почему»), часть осталась, часть
добавлена.

Серьёзность: **важно** — данные теряются, паника, пользователю говорят не
то, что происходит, или код ведёт себя не так, как сам о себе говорит.
**мелочь** — медленно, неудобно читать, правило нарушено формально.

## Что снято и почему

Прежние версии файлов содержали замечания, которые ревью не должно было
делать. Они сняты и не вернутся:

| Снято | Почему |
| --- | --- |
| «Конфиг не валиден по TOML, его не прочитает сторонний инструмент» | Формат конфига — выбор проекта, он рабочий, и правила проекта его не нарушают. Внешние инструменты вне рамок ревью |
| «Ширина символов нужна для отрисовки» | Отрисовки ещё нет, это отдельная задача проекта |
| «Разделитель разрядов лучше неразрывным пробелом» | Вкусовое замечание, не нарушение правил |
| «Имя команды стоит ограничить белым списком» | Вкусовое замечание |
| «Имя темы стоит разрешить в кириллице» | То же |
| «После переименования надо синхронизировать каталог» | Требования к прочности записи в правилах проекта нет, атомарность есть |
| «`for _ in` нарушает правило про `_` в именах» | `_` в `for` — не имя, правило не нарушено |
| «Надо бы проверять, что файл читается посторонним парсером» | Внешний критерий |

## Сводка по крейтам

### `claxis-text`

- 507 строк, 23 теста, все проходят.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** `substitute` подставляет значения по порядку, и значение, вставленное
  раньше, может быть изменено более поздней заменой. Комментарий в тесте и
  имя теста утверждают обратное.
- **Мелочь:** `substitute` делает по одному проходу на каждое значение.

### `claxis-core`

- 1858 строк, 57 тестов, все проходят, есть бенчмарк.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** у курсора два представления о выделении — поле `selecting` и
  неравенство якоря и головы. Они расходятся: `select_to` в ту же позицию даёт
  `is_selection() == false`, но следующее движение создаёт выделение.
- **Важно:** длина документа живёт в двух местах — в `LineMap` и у вызывающего.
- **Важно:** пространство имён команд непоследовательно: `edit::move::word::left`
  рядом с `edit::move::up` у буфера.
- **Мелочь:** две модели позиции в крейте (`u32` и `usize`), молчаливый отказ
  движения при рассинхроне строки, `O(строк)` на правку карты, прыжок на
  1,0–1,8 мкс.

### `claxis-buffer`

- 2705 строк, 116 тестов, все проходят, есть бенчмарк.
- Нарушения правил `AGENTS.md`: молчание в `snapshot()`, файл рядом с лимитом.
- **Важно:** `History::restore` разбирает блоб сам и не проверяет `head >= anchor`
  — на битом блобе `head - anchor` переполнится.
- **Важно:** `Document::apply` — публичный метод без проверок границ.
- **Важно:** `undo` считает длину как `head - anchor` без `abs_diff`, хотя в
  соседнем файле для того же случая `abs_diff` применён.
- **Важно:** `Document::snapshot` молчит, когда приёмник отказал.
- **Мелочь:** отпечаток базы пересчитывается на каждый снимок, `tree.rs` — 985
  строк впритык к лимиту.

### `claxis-disk`

- 3065 строк, 96 тестов, все проходят.
- Нарушения правил `AGENTS.md`: `expect` в тестовой утилите, `#[expect]`
  вместо запрещённого `#[allow]`, `snapshots.rs` — 1409 строк.
- **Важно:** имя временного файла — только имя цели и pid: две записи одного
  пути из одного процесса получат одно имя, и вторая перезапишет первую.
- **Важно:** значения по умолчанию заданы дважды — в `claxis-disk/src/defaults.rs`
  и в схеме конфига; ключ в диске назван `keep`, а настоящий путь —
  `General.snapshots_keep`.
- **Мелочь:** `touch` в наблюдении линейный, мёртвый публичный API, две разные
  суммы (XXH3 и FNV-1a) в одном крейте.

### `claxis-save`

- 612 строк, 16 тестов, все проходят.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** зазор между проверкой и записью: между сверкой и записью файл
  может измениться снаружи, и чужая правка будет затерта, а правка снаружи
  исчезнет незаметно. В этом зазоре главное обещание крейта не выполняется.
- **Важно:** файл записан, а якорь обновить не удалось — редактор после этого
  считает, что файл изменили снаружи, и отказывается сохранять заново.
- **Важно:** правило проверки реализовано дважды (`verify` и `write`) и
  отвечает по-разному.
- **Важно:** `DEFAULT_RETENTION = "7d"` — второе место правды о значении по
  умолчанию.
- **Мелочь:** текст отказа собирается английским каталогом, разбор срока
  принимает «2 d» и отвергает «7D».

### `claxis-input`

- 357 строк, 18 тестов, все проходят; зависимостей нет.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** заголовок крейта обещает «клавиши как позиции, раскладки,
  модификаторы, составление, лидер, отмена» — сделано только удержание.
- **Важно:** тип `Tap` не используется нигде и дублирует половину `Resolved`.
- **Важно:** вариант `Resolved::Waiting` никогда не выдаётся.
- **Мелочь:** три имени для окна в миллисекундах.

### `claxis-term`

- 846 строк, 22 теста, все проходят.
- Нарушения правил `AGENTS.md`: поле `super_` (имя с `_`).
- **Важно:** проверка поддержки протокола может висеть бесконечно — чтение
  stdin блокируется, а срок 100 мс проверяется только между чтениями. Свой
  же код обещает «ждать вечно нельзя».
- **Важно:** введённые во время опроса символы теряются — прочитанное
  отбрасывается, кроме ответа.
- **Важно:** аварийные сообщения печатаются английским каталогом в `stderr`,
  минуя каталог пользователя.
- **Важно:** чтение только блокирующее — метода «прочитать, если есть» нет,
  а без него таймеры в цикле не тикают.
- **Мелочь:** двойное отключение raw mode, в событии мыши нет модификаторов.

### `claxis-i18n`

- 856 строк, 31 тест, все проходят.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** в крейте два `samples()`: в `lib.rs` и в `messages.rs`. Первый
  дублирует второй, но не полностью, и никем не используется.
- **Важно:** `Catalog::get` ищет линейно по вектору — `O(n)` на каждый
  перевод, а переводы берутся на каждый элемент интерфейса.
- **Мелочь:** `duplicates` работает за `O(n²)`, правило слияния при
  одинаковом ключе не зафиксировано.

### `claxis-theme`

- 943 строки, 40 тестов, все проходят.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** крейт не умеет читать тему: содержимое файла не разбирается, типа
  «тема с набором цветов» нет, `Color::parse` существует сам по себе.
- **Важно:** тест `a_file_that_is_not_readable_is_an_error_not_a_silent_gap`
  обещает ошибку в имени и проверяет обратное.
- **Мелочь:** обёртка `error::samples()`, `O(n²)` в списке тем.

### `claxis-config`

- 3250 строк, 67 тестов, все проходят.
- Нарушения правил `AGENTS.md`: файл больше тысячи строк, молчаливый дефолт при
  неверном типе, дублирование значений по умолчанию.
- **Важно:** значения по умолчанию в схеме написаны литералами, а не
  ссылками на константы крейтов.
- **Важно:** неверный тип значения молча заменяется значением по умолчанию.
- **Важно:** `generate.rs` — 1283 строки.
- **Мелочь:** `unknown_keys` считает ключи внутри табличных настроек
  неизвестными, номер строки не ищется для секций с комментарием.

### `claxis-commands`

- 1341 строка, 47 тестов, все проходят.
- Нарушений правил `AGENTS.md` нет.
- **Важно:** крейт ничего не выполняет, хотя команды объявляют и обещают
  выполнять (`edit::move::word::left`, `edit::undo`).
- **Важно:** проверка конфликта привязок перебором всей таблицы — `O(n²)` на
  загрузку конфига.
- **Важно:** `register` сортирует весь список после каждой регистрации.
- **Мелочь:** линейные поиски в реестре, называется только один из
  конфликтующих уровней.

### `claxis` (корень: `src/api`, `src/router`)

- 6075 строк, 143 теста в корне (676 по проекту), все проходят.
- Нарушений правил `AGENTS.md` семь; три бьют по пользователю прямо.
- **Важно:** весь пользовательский текст собирается английским каталогом
  (`let messages = En`), хотя каталог выбранного языка уже загружен и лежит в
  `Editor`. Правило «переводится всё, что видит пользователь» не выполняется.
- **Важно:** восстановление правок прошлого запуска молча проглатывает ошибки
  (`ok().flatten()`, `if let Ok(...)`) — правки не показываются, и человек об
  этом не узнаёт.
- **Важно:** свежий конфиг создаётся с пустым каталогом — комментарии всегда
  английские, при любом языке.
- **Важно:** `session.rs` — 2229 строк, `editor.rs` — 1365.
- **Важно:** ещё два места правды о значениях по умолчанию (`7 * 24 * 60 * 60`
  и 300 секунд).
- **Важно:** `Ctrl-Q` и `Ctrl-S` зашиты в цикл, хотя правило требует действия
  пользователя через систему команд.
- **Мелочь:** цикл стоит на блокирующем чтении, пустой путь как «новый файл»,
  ошибки кеша запасного конфига глотаются, наблюдение не переподписывается.

## Общий итог

Двенадцать крейтов, 21 тысяча строк, 676 тестов.

**Что сделано хорошо и не трогаем:**

- **Границы между крейтами проверяются тестами, а не памятью.** Забыть ручку
  легко, и тогда связи расползутся по кодам — тест это ловит.
- **Эталон рядом с быстрым путём.** В `claxis-text`, `claxis-core` и
  `claxis-buffer` медленный заведомо правильный способ живёт рядом с
  оптимизированным, и тесты сверяют их на всём пространстве состояний.
- **Ошибки не теряются и не молчат.** Каждый крейт отдаёт структуру, каталог
  собирает текст, примеры есть у каждого ключа.
- **Проверки идут до побочных действий.** Правка, которой не хватило места,
  не стоит потерянной ветки отмены.
- **Чужой правке на диске нельзя уехать под следующим сохранением.** Якорь
  «база ↔ диск», две ступени, отказ при расхождении.

**Что бьёт по пользователю прямо:**

1. **Локализация в бинарнике не работает** — каталог загружен и не используется.
   Правка на несколько строк.
2. **Правки прошлого запуска могут пропасть молча** — ошибки при чтении снимка
   и восстановлении истории проглатываются.
3. **Проверка протокола терминала может зависнуть** вместо внятного отказа,
   который уже обещан.
4. **Зазор между проверкой и записью файла** — чужая правка может быть затерта
   в этом зазоре.
5. **Свежий конфиг получает английские комментарии** при любом языке.

**Что мешает работе и по проекту впереди:** исполнение команд, состояния и
режимы, ввод текста, отрисовка. Без них редактор нельзя назвать редактором.

| Не глотать ошибки восстановления | `claxis` | молчаливую потерю правок |
