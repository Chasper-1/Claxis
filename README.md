# Claxis

Терминальный редактор для новичка: широкий функционал, простая настройка, низкий
порог входа. TUI-only, GUI не делается.

## Статус 0.5.7

Редактор запускается, читает файл, следит за конфигом, снимает снапшоты по
времени и по глубине истории, выходит по `Ctrl-Q`. Курсор и токены готовы в
ядре, но к редактору ещё не подключены; отрисовки и ввода текста нет.

Сделано:

- `claxis-text` — локальные границы графем: буквы с комбинирующими знаками,
  эмодзи, флаги и Hangul остаются целыми.
- `claxis-core` — курсор, выделение, прыжки по буквам, числам и символам,
  карта строк с `LF`, `CRLF` и `CR`.
- `claxis-buffer` — документ на сбалансированном дереве листьев над общим
  буфером, история, снапшоты правок поверх файла по времени и по глубине.
- `claxis-disk` — вся работа с диском: атомарная запись, кеш снапшотов,
  наблюдение за файлами.
- `claxis-config` — конфиг в нескольких файлах, создаётся со всеми ключами и
  комментариями, применяется на лету.
- `claxis-i18n`, `claxis-theme` — переводы и темы файлами.
- `claxis-term` — kitty keyboard protocol, внятный отказ без него.
- `claxis-commands` — реестр команд, алиасы, автодополнение по уровням;
  выполнения пока нет.

## Требования к терминалу

Нужен kitty keyboard protocol: kitty, WezTerm, foot, Ghostty, конфигурация
Windows Terminal. Остальные получают внятное сообщение и отказ.

## Сборка

```sh
cargo b -r
cargo bench   # ядро и буфер
```

Собранный редактор запускается без команды. Отладочные команды:

```sh
claxis messages   # все сообщения всех крейтов
claxis help       # справка
```
