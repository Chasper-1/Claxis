# Claxis

Терминальный редактор для новичка. Функционал широкий, настройка простая,
порог входа низкий.

Rust, ratatui, crossterm. TUI-only, GUI не делается: ниша — редактор в
терминале, где он может быть лучшим.

## Статус

Редактор пока не запускается: терминального цикла ещё нет, `main.rs` печатает
заглушку. Готова инфраструктура под ним.

### Версия 0.2.4

Сделано:

- **Буфер** — piece tree с балансировкой, узел и сегмент по 16 байт, пул
  узлов считается от глубины истории, ни одной паники.
  Подробнее: [буфер](docs/Ru/buffer.md), [буфер и курсоры](docs/Ru/buffer-and-cursors.md).
- **Хранилище снапшотов** — sqlite в кеше ОС, кольцо по файлу.
- **Связка** — снапшоты с буфера пишутся на диск через маршрутизатор, переживают
  перезапуск. Крейты друг о друге не знают. Подробнее:
  [архитектура](docs/Ru/architecture.md).
- **Локализация** — механизм каталогов и подстановки. Настоящих языков, кроме
  английского, пока нет. Подробнее: [локализация](docs/Ru/i18n.md).
- **Терминал** — kitty keyboard protocol, raw mode, свои типы событий.
  Отказ без протокола. Подробнее: [архитектура](docs/Ru/architecture.md).
- **Настройки по крейтам** — каждая живёт в своём крейте: буфер, стор, ввод.
- **Конфиг** — четыре файла плюс папки тем и переводов. При первом запуске
  создаётся всё со всеми ключами и комментариями. Сохранение сразу применяется;
  сломанная секция отключается, остальные работают; последний корректный
  конфиг лежит в кеше.
- **Конфиг и перевод** — отдельные крейты, конфиг зависит от локализации.
  Подробнее: [конфиг](docs/Ru/config.md), [локализация](docs/Ru/i18n.md).
- **Общее форматирование** — `claxis-text`, без копий по крейтам.
  Подробнее: [архитектура](docs/Ru/architecture.md).

Тестов 166. Не сделано: остальные крейты. Список открытого —
[MVP и roadmap](docs/Ru/mvp.md).

## Требования к терминалу

Нужен терминал с kitty keyboard protocol: kitty, WezTerm, foot, Ghostty,
конфигурация Windows Terminal. Модель ввода требует событий отпускания, а
без протокола нельзя отличить «отпустил Alt» от нового нажатия. Остальные
терминалы получают внятное сообщение и отказ.

## Что задумано

- Буфер по модели `Original` + `Add Arena`, поверх — сбалансированное дерево сегментов, история ограничена числом записей. Копий документа нет, большие файлы деградируют стабильно.
- Режим без зависимости от языка в данный момент. Раскладки переключаются свободно.
- Два способа набора: `Alt` пишет символ как есть, `Ctrl` — позицию клавиши. Оба переназначаются.
- Три состояния — `edit`, `command`, `files` — и режимы внутри них.
- Команды вида `:std::edit::move::up`, алиасы и хоткеи на трёх уровнях: `global` → `state` → `regime`.
- Конфиг в TOML с точечной записью: комментарии и порядок ключей сохраняются.
- Интерфейс полностью переводится, имена команд не переводятся.
- Плагины двумя уровнями: TOML-макросы без логики и wasm в песочнице.
- Без сплитов, допускается разделение экрана до двух файлов, эмуляции терминала и собственных метаданных внутри документа.
